# פרק 5 — פריסה ובקרה בדפדפן

## השורות מלמעלה למטה

1. **פאנל 1:** קריאת זמן (שלוש ספרות), ◀ צעד אחורה, נגינה/השהיה (עיגול ירוק), ▶ צעד קדימה. הצעד: <span dir="ltr">`step`</span>, ברירת מחדל 10 מילישניות.
2. **פאנל 2:** `none` / `all` (כל האודיו), ‏`FFT` / `WAVE`. כל כפתור נושא את שם הפעולה הבאה שלו.
3. **עמודת שמות:** תיבת סימון ושם לכל אודיו; חץ קטן ושם לכל אנוטציה. גרירה של התיבה או של השם משנה את סדר השורות.
4. **עמודת דוברים:** תווית צבעונית לכל דובר, רק לאנוטציות שהחץ שלהן פתוח. נעלמת כשאין אנוטציה פתוחה.
5. **שורות אודיו:** גל קול או ספקטרוגרמה, <span dir="ltr">`height`</span> פיקסלים כל אחת. כשנבחרו שני אודיו או יותר מופיעה שורת **mix** במסגרת כחולה: ממוצע האודיו הנבחר, כלומר מה שנשמע.
6. **ציר זמן.** צפיפות הסימונים מתעדכנת בכל זום.
7. **נתיבי דוברים:** <span dir="ltr">`row_height`</span> פיקסלים לדובר. הקטעים הם פסים צבעוניים ללא טקסט; שם הדובר ב-tooltip ובעמודה.

## פעולות

| פעולה | תוצאה |
|---|---|
| גלגלת העכבר מעל הגל | זום סביב הסמן; גלילה אופקית מזיזה |
| לחיצה על הגל או על הספקטרוגרמה | קפיצה; מצב הנגינה לא משתנה |
| רווח | נגינה / השהיה |
| ← / → | הזזה ב-`step` |
| תיבת סימון | השתקה (10 מילישניות של דעיכה); השורה מולבנת; השמע ממשיך |
| לחיצה על שם | מחזור: רגיל → השארת הקטעים (מסגרת אדומה) → השארת ההשלמה (מסגרת מקווקוות) → רגיל |

## מסכות

שם אנוטציה פירושו איחוד כל הדוברים שלה. שם דובר פירושו הדובר בלבד. כמה שמות פעילים נחתכים. מחוץ לתוצאה האודיו מושתק, האזור מולבן, וקו הנגינה מדלג לקטע הבא ונעצר אחרי האחרון. ציר הזמן נשמר, כך שהקטעים נשארים במקומם ביחס לציר ולאנוטציות האחרות.

## מקרי שימוש

- **Missed speech של דובר.** `reference/SPEAKER_01` ועליו `!hypothesis/SPEAKER_01`: נשמעים רק הרגעים שבהם הייחוס אומר SPEAKER_01 וההיפותזה לא.
- **חפיפת דוברים.** שני שמות דוברים מאותה אנוטציה: החיתוך הוא בדיוק האזורים שבהם שניהם מדברים.
- **False alarm.** `!reference` לבדו: כל מה שאינו דיבור לפי הייחוס; אם ההיפותזה מסמנת שם דובר, זו התראת שווא.
- **השוואה של stems.** בהפרדת דוברים, השתקת ה-stem של דובר א' ומסכה על הדובר שלו: נשמעת רק הדליפה שלו לתוך stem ב'.
