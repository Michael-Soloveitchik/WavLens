# פרק 11 — מילון מונחים

| Term (EN) | מונח (HE) | הגדרה במשפט אחד |
|---|---|---|
| Speaker Diarization | דיאריזציה של דוברים | חלוקת הקלטה לקטעים לפי "מי דיבר מתי". |
| Speaker Recognition / Identification | זיהוי דוברים | שיוך קטע דיבור לדובר מתוך קבוצה ידועה. |
| Speaker Verification | אימות דוברים | הכרעה אם קטע דיבור שייך לדובר נטען. |
| Speaker Separation / Source Separation | הפרדת דוברים / הפרדת מקורות | פירוק תערובת לאותות הנפרדים של כל דובר (stems). |
| Speech Enhancement | שיפור דיבור | הסרת רעש והד מאות דיבור. |
| SAD / VAD (Voice Activity Detection) | זיהוי פעילות קולית | סימון האזורים שבהם יש דיבור. |
| Reference / Hypothesis | ייחוס / היפותזה | האנוטציה האנושית מול פלט המודל. |
| DER (Diarization Error Rate) | שיעור שגיאת דיאריזציה | סכום הדיבור שפוספס, הדיבור המדומה ובלבול הדוברים, מחולק במשך הדיבור. |
| Missed Speech / False Alarm / Confusion | פספוס / התראת שווא / בלבול | שלושת רכיבי ה-DER. |
| RTTM | RTTM | פורמט טקסט של NIST לקטעי דוברים, שורה לכל קטע. |
| UEM | UEM | קובץ שמגדיר אילו אזורים של ההקלטה נכנסים לניקוד. |
| SegLST | SegLST | פורמט רשומות JSON של meeteval לקטעים עם דובר ותמליל. |
| Lane | נתיב | שורה אופקית אחת של קטעים, אחת לכל דובר. |
| Mask / Solo | מסכה | השארת קטעים נבחרים בנגינה והשתקת השאר. |
| Complement | השלמה | כל מה שמחוץ לקטעי השם שנבחר. |
| Intersection | חיתוך | הקטעים המשותפים לכל המסכות הפעילות. |
| Mix | ‏mix | ממוצע האודיו הנבחר, כלומר מה שנשמע בפועל. |
| Mel Spectrogram | ספקטרוגרמת mel | ספקטרוגרמה שציר התדר שלה מעוות לפי סולם mel, התואם לתפיסת הגובה האנושית. |
| STFT | התמרת פורייה קצרת-זמן | התמרת פורייה על חלונות קצרים וחופפים לאורך הזמן. |
| Hop / Window | קפיצה / חלון | המרחק בין פריימים ואורך הפריים ב-STFT. |
| Playhead | קו נגינה | הקו האדום שמסמן את מיקום הנגינה הנוכחי. |
| Trait | תכונה מסונכרנת | שדה של הווידג'ט שמסונכרן בין Python לדפדפן. |
| anywidget | anywidget | תשתית לווידג'טים של Jupyter עם קובץ JavaScript אחד. |
